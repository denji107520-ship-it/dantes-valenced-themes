# 🌸 Dante's Valenced Themes

A collection of custom themes for **Valenced**, created and provided by **Dante**.

---

## 📦 Repository URL

Copy and paste this link into Valenced (**Settings → Valenced → Repositories → Add Repository**):

```text
https://raw.githubusercontent.com/denji107520-ship-it/dantes-valenced-themes/main/zerotwo-sakura-darling.zip

```

## 🎨 Available Themes

### **Zero Two — Sakura Darling**
* **Description:** Frosted sakura pink & deep rosewood Zero Two theme — provided by Dante
* **Features:**
  * Full Zero Two pink text, icons, and channel list
  * Deep rosewood frosted chat & navigation bars
  * Custom Zero Two sakura background wallpaper

---

## 🛠️ How to Install
1. Open **Valenced** on your device.
2. Go to **Settings → Valenced → Repositories** (or **Plugins → Repositories**).
3. Tap **Add Repository** and paste the **Repository URL** above.
4. Install **Zero Two — Sakura Darling** from the repository list.
5. Go to **Settings → Valenced → Themes**, select **Zero Two — Sakura Darling**, and tap **Reload to apply changes**.
